Tortoise Blocks は、子どものためのビジュアルプログラミングアプリです。ブロックをいくつか並べて再生ボタンを押すと、カメがキャンバスに絵を描いていきます。線は1本ずつ引かれ、そのとき動いているブロックがプログラムの中で光ります。

■ ならべるだけのブロック
まえへ、みぎへまわる。ペンをおろし、色を選び、形を塗る。ドラッグして置いても、タップして足してもかまいません。数字はその場で直せて、やったことはすべて元に戻せます。作り直したくなったら、ゴミ箱をタップすればプログラムごと消せます。

■ くりかえし・もし・はこ
ブロックのまとまりを何度もくりかえす。条件をたずねて、どちらかの道を進む。数を「はこ」に入れて、動かしながら足していく。プログラミングの本物の考え方を、子どもがすでに知っている言葉のまま扱えます。

■ じぶんのブロック
ブロックに名前をつけて、好きな中身を入れて、プログラムのどこからでも名前で呼び出せます。自分で自分を呼ぶこともできます。少しずつ小さくしながら二回呼べば、それだけで木が描けます。自分で作る前に、できあがった木のみほんを見てみてください。

■ サイコロをふる
数にも色にも、サイコロを入れられます。すると同じプログラムなのに、動かすたびに違う絵ができあがります。「もう一回」がそれだけで遊びになります。

■ 描かれていく様子が見える
再生と一時停止、1コマずつ進める・戻す、シークバーで行き来、途中で速さを変える。いま描いているブロックは光ったままなので、どのブロックがどの線を描いたのかが必ずわかります。

■ ブロックは Swift になる
もうひとつのペインには、同じプログラムが本物の Swift のコードとして表示されます。エディタのように色が付き、コピーもできます。ブロックでは足りなくなったその日のために、最初からそこにあります。

■ のこす・わたす
作品はふつうの書類として「ファイル」や Finder に並び、アイコンがその絵そのものになります。同じ四角が並ぶのではなく、フォルダがそのまま作品集になります。SVG や PNG で書き出したり、共有シートで送ったりもできます。

■ 保護者・先生の方へ
ログインもアカウントもありません。入力するのは数字だけです。広告も、利用状況の計測も、第三者製の SDK もありません。ネットワーク通信は一切行わず、そもそもアプリの中に通信を行うコードが含まれていません。作った作品は、端末と、選んだ保存先にだけ残ります。

Tortoise Blocks は iPad と Mac で動き、日本語と英語に対応しています。MIT ライセンスのオープンソースで、無料です。
